# Умовні профілі χ² V4.8
Розпакувати V48_UNCERTAINTIES у F:\TDE\UGC11487_V4_FIXED.
Потрібні існуючі V48_PAPER_FINAL, V48_LOCAL_PAIR і results/v48_parallel_final.
Не запускати одночасно з іншим fit: вони використовують спільний кеш.

Перевірка:
python -u V48_UNCERTAINTIES\run_profiles.py --check-only

Перший профіль (eta, обидва кандидати, 4 незалежні напрямки):
python -u V48_UNCERTAINTIES\run_profiles.py --parameter eta --workers 12

Всі сім профілів (eta повторно використовується):
python -u V48_UNCERTAINTIES\run_profiles.py --parameter all --workers 12

Використовуються нові best.json: local chi2=58.95064072368716 та grid=59.754338041150255.
При кожній фіксованій величині Powell повторно підбирає інші фізичні параметри;
t0 профілюється solver, окрім профілю самого t0. Там для кожної фізичної моделі
використовується фіксований t0 і повторно підбираються шість фізичних параметрів.
Ніяких змін фізичного solver або фотометричних похибок.

За замовчуванням: maxfev=240 на точку, 5 зовнішніх кроків на напрямок,
до 3 уточнень дужки для кожного рівня Δχ²=1 і 3.841459.
Це номінальні однопараметричні рівні 68.27% та 95%, за припущень likelihood-ratio
методу; це не спільні семивимірні області та не повна модельна невизначеність.
Повні профілі можуть тривати декілька діб. Перший eta-профіль дає вимір часу.
--workers 12 задає максимум процесів; для одного параметра є лише 4 напрямки.
Спільні геометричні кеші захищені блокуваннями в межах цього запуску.

Результати: results/v48_uncertainties.
Архів SEND_UNCERTAINTIES_FOR_REVIEW.zip містить профілі, параметри всіх точок,
статуси та PDF. Невдалі оптимізації позначено червоними хрестиками.
PDF призначені для діагностики, а не остаточних довірчих інтервалів у статті.
Автоматично сертифіковані інтервали не випускаються: треба перевірити збіжність,
перетини рівнів, чисельну стабільність та baseline. Для grid опорний мінімум
завершився за бюджетом. Нижче знайдене chi2 більш ніж на 0.01 зупиняє
відповідний напрямок із повідомленням, яке вимагає оновити baseline.

Повтор тієї самої команди відновлює завершені точки. Зміна maxfev/points/refine
потребує нової --output папки; фізичний кеш зберігається.
Переривання Ctrl+C може чекати завершення активних задач. Краще дочекатися
SIDE FINISHED; кожна завершена точка записується окремо.

Перевірено синтаксис, аналітичний квадратичний профіль, уточнення дужок,
повторний запуск і обробку незбіжної оптимізації. Повний фізичний розрахунок
нових профілів у середовищі автора пакета не запускався.
