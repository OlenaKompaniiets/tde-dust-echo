## 1. Зараз: додати всі графіки до вже порахованого кандидата

```
python -u V48_LOCAL_PAIR\run_pair.py --mode figures
```

Автоматично вибирається остання папка results/v48_local_reproduce_*/candidate
із thermal_solution.npz. Шлях друкується. Для вибору іншої папки:
--solution "повний шлях до candidate". RT не запускається.
Викликається ваш scripts/v48_paper_products.py без змін. Створюються:
paper_flux_flux_errors, paper_colour_evolution, paper_temperature_radial_evolution,
paper_temperature_time (PDF/PNG), температурні CSV, grain_sizes.csv,
energy_ledger.csv, paper_products.json. Початкові angular_rt_lightcurves,
temperature_map, thermal_evolution_3d уже зберіг solver із --plots.
Похибки потоків/кольору відповідають прийнятим sigma, із error floor.
Це той самий набір великого рану, не нові GIF або виправлена геометрія розрізу.

## 2. Кутова перевірка двох кандидатів: чотири розрахунки

```
python -u V48_LOCAL_PAIR\run_pair.py --mode angular --workers 2
```

Кожна вихідна модель рахується з fine (nmu=6,nrays=256,nobserver=512)
та angular (nmu=12,nrays=512,nobserver=1024). Решта параметрів незмінні:
nr=6, nwave=144, dt_RT=30 діб, stop=15000 діб, seed=481.
Заново профілюється t0. Перевірка лише кутової чутливості, не повний доказ
просторової/часової/спектральної збіжності. Якщо зміни істотні відносно
різниці між кандидатами, спочатку обрати стабільнішу роздільність.
Фіксованого універсального порога delta chi2 не нав'язано.
Вихідні STARS: m3.0_t0.0/0.850.dat та m0.7_t1.0/0.800.dat.
Для обох моделей зберігаються повні arrays і всі графіки великого рану.

## 3. Після аналізу кутової перевірки: локальне уточнення

```
python -u V48_LOCAL_PAIR\run_pair.py --mode refine --workers 2
```

Fine-пошук: 4 послідовні проходи по eta, tau_visc, tau_C, tau_E, theta, inc.
На кожному кроці обчислюються обидва напрямки від поточного рішення,
приймається кращий із них або залишається поточне. Кроки зменшуються
вдвічі після проходу. Максимум 49 evaluations на STARS (98 разом),
плюс повтор двох фіналістів із --plots. Кеш зменшує фактичну кількість.
Дві STARS гілки виконуються паралельно; одна модель не використовує 16 workers.
Бюджет скінченний: це локальне уточнення, не глобальна оптимізація чи posterior.
Немає критерію доведеної збіжності оптимізатора після 4 проходів.
Параметри, межі та кроки явно наведено в search_plan.json:
eta 0.10–0.22 (початковий крок .015), visc 100–400 d (50),
tau_C .2–.8 (.05), tau_E 1.2–3.4 (.3), theta та inc 30–55 deg (5).
Це обраний контрольний діапазон, не довірчі інтервали.
Rin/Rout/p, склад/розміри зерен, host, похибки та driver family фіксовані.
Немає додаткових penalties: відбір лише за chi2 повних W1+W2 кривих.
Граничні параметри фіналістів позначаються у best.json.

## Результати та відновлення

Папки results/v48_pair_<режим>_<fingerprint> окремі від завершеної сітки.
Повтор тієї самої команди використовує завершені обчислення, проходи
відтворюються детерміновано з початкового стану. Не змінюйте файли під час запуску.
Зміна коду/даних/плану створює інший namespace. Solver додатково перевіряє
повний provenance, включно зі STARS. Старі результати не перезаписуються.
Помилка solver зупиняє гілку з посиланням на run.log; її НЕ трактують як
поганий фізичний фіт або zero-MIR. Після завершення з'являється
SEND_PAIR_FOR_REVIEW.zip (без великих NPZ). Надішліть його для аналізу.

## Що змінено в solver

solver.py є копією вашого надісланого run_v48_grid_model.py. Додано тільки
аргумент --angular-check та перевизначення трьох чисельних параметрів.
Фізичні src модулі та функції paper products використовуються з вашого проекту.
Статична непрозорість, sublimation gate, та ефективне осесиметричне середовище
залишаються припущеннями моделі. 3D точки не є індивідуальними clumps.
Перевірка синтаксису та контроль пошукового алгоритму виконані;
нові фізичні пошуки тут не запускалися.
