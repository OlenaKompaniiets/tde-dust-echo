What do time and temperature mean?

Local time is measured in the source rest frame relative to the unsmoothed fallback peak. At each point the stored solution is sampled at u = tlocal − r/c. These are simultaneous local snapshots, not images at one observer-arrival time.

The default temperature is ⟨T⟩N = ΣNaTa/ΣNa. The size selector shows the actual stored temperature for either end of the grain-size grid. Points outside the stored time support have no assigned temperature. Cold material is rendered more transparently; display opacity does not encode optical depth.

Background heating is absent in the model. Near-zero computed values before illumination do not measure the galaxy's quiescent dust temperature. Points sample an effective medium; their density is not a map of physical grain density.

Data and browser sampling

The browser uses every second original spatial sample (1152 points), and 101 local-time frames from 0 to 5000 d. Values are interpolated from thermal_solution.npz and rounded to 0.01 K for display. Full-precision scientific arrays remain in the repository. The camera orientation is for exploration and does not alter the fitted viewing inclination.
