Work through UGC 11487

A complete route through the supplied UGC 11487 example, with commands and expected outputs at every stage.

Step 1 of 8

Get the project

Download the repository or clone it. Keep this project separate from any active long-running grid or uncertainty calculation.

git clone https://github.com/OlenaKompaniiets/tde-dust-echo.git
cd tde-dust-echo

While the repository is private, GitHub access is required. Download the repository ZIP if you do not use Git. Extract the ZIP before proceeding.

Expected: folders src, scripts, tools, data, configs, docs, and examples.

Step 2 of 8

Install and check inputs

In Anaconda Prompt on Windows, run these commands from the repository root:

conda env create -f environment.yml
conda activate ugc-dust
python tools/check_install.py

If the environment already exists, activate it without recreating it. The checker reads packages and input hashes; it does not start an RT run.

Expected: package versions, 141 STARS histories, and PASS. If a scientific input has intentionally changed, review the difference before updating its reference checksum.

Step 3 of 8

Inspect the WISE table

Open data/UGC11487_WISE_TDE_model_input_22epochs.csv. Each row is one observed epoch. The current UGC loader requires exactly 22 rows.

Download the canonical CSV · Inspect the data interactively

ColumnMeaning
mjdObserver-frame epoch
F_W1_Jy, F_W2_JyTotal measured flux density, Jy
sigma_W1_Jy, sigma_W2_JyEffective uncertainty used directly in the fit, Jy

The supplied uncertainties include the adopted 1.10 mJy floor in quadrature with the statistical error. Do not add the floor again. The table also retains statistical-error columns for inspection. The exact fixed hosts are 8.0723159840 mJy (W1) and 5.2154145825 mJy (W2).

Check: Jy versus mJy, finite values, positive errors, and constant host columns. Do not subtract the host in the CSV: the solver subtracts it in the likelihood.

Step 4 of 8

Read the physical configuration

Use configs/case_a.json for exact reproduction. Download the reference configuration.

STARS history: input/m3.0_t0.0/0.850.dat. The compact population occupies 0.25–0.5 pc with p = 0; the extended one occupies 1–2 pc with p = 2. Both see the same source. η ≈ 0.15176 and τvisc ≈ 245.23 d determine the illuminating history.

τC ≈ 0.39028 and τE ≈ 2.03767 normalize source-weighted absorption depths; they are not days. θ ≈ 47.3308° is the polar opening angle and i ≈ 43.4449° the observer inclination.

Do not interpret legacy grid fields in the physical configuration as all active runtime settings. summary.json → numerics records the actual transport discretization. The reference fine run has 72 thermal cells and 41 grain sizes.

For another object: review distance, redshift, black-hole mass, input length, fixed hosts and event-epoch bounds in the input guide. The current package is not a universal one-file configuration interface.

Step 5 of 8

Check the archived reference

python tools/check_saved_case.py

This recomputes χ² directly from the saved observed fluxes, predictions and errors. It is quick and does not solve radiative transfer.

W1  19.4879842481
W2  39.4626564756
Total χ²  58.9506407237
Nominal conditional degrees of freedom  37

The 37 degrees of freedom use 44 band measurements and seven continuous fitted quantities. They are conditional on the selected driver, fixed geometry and grain assumptions.

Step 6 of 8

Run one physical model

python -u tools/run_case_a.py --plots

The command creates a fresh results/case_a_... directory and preserves existing results. Stages printed in the terminal include ray transport, thermal iterations and W1/W2 observer transfer.

The prepared package was tested in a fresh Linux/Python 3.12 environment: χ² = 58.95133488, Δχ² = 0.00069416 from the archived run. Solver time there was approximately 171 s; this is a benchmark for that environment, not a promise for your machine.

Expected: successful completion, summary.json, response.csv, epochs.csv, thermal_solution.npz and plots. An existing-fingerprint mismatch should be resolved by using a new output folder, not by bypassing provenance checks.

Step 7 of 8

Validate and interpret the result

Open summary.json and inspect the quantities below together.

  • fit: total and band χ², event epoch and boundary flag.
  • numerics: actual cell, wavelength, time and ray resolution.
  • final_iteration: iterative changes, distinct from resolution convergence.
  • energy: source, absorbed, escaping and recycled emission.
  • static_opacity_gate_passed: whether the calculation remains inside the adopted temperature domain.

For Case A, directly absorbed energy is approximately 5.30132×1051 erg and eventually escaping IR energy approximately 5.30131×1051 erg. The maximum individual-grain temperature is 1143.58 K, below the adopted 1793.30 K threshold.

A good energy balance does not prove uniqueness of the geometry. Inspect residuals and independent resolution checks before interpreting small χ² differences.

Step 8 of 8

Make figures and proceed to inference

python tools/plot_thermal.py --folder examples/case_a

For a new result, replace examples/case_a with its actual result folder. Corrected thermal figures are written in thermal_publication_v2. Use the interactive explorer to understand the reference temperature field; it always uses archived Case A, not your new local output.

Only after reproducing a single model should you launch the staged search:

python -u scripts/run_v48_staged.py --workers 12

This may schedule thousands of models. Benchmark memory and runtime first. The retained local-search and uncertainty workflows require their documented baseline/checkpoint state; they are not automatic next steps of this example. Final validated confidence intervals have not been included.

For the paper: preserve observed error bars, report χ² with ν, identify the host and error model, and distinguish local thermal time from observer time.
