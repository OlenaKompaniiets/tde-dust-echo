Scope

The source is a scaled STARS fallback history with causal accretion smoothing. Two radial dust populations form an axisymmetric effective medium. The solver follows direct absorption, thermal emission, secondary absorption, propagation delays, and observer-direction escape. Grain temperatures depend on position, time, and grain size.

This release uses static opacity. A temperature threshold identifies configurations outside this solver's domain; the production V4.8 solver does not evolve irreversible grain destruction. The rendered points sample the effective medium, not resolved physical clumps.

Two useful entry points

Saved results can be checked without an RT calculation. A separate command reruns the archived Case A configuration. The staged grid and uncertainty tools are documented as advanced, project-specific workflows.

The package is currently specialized to UGC 11487. Redshift, luminosity distance, black-hole mass, the observation count, and event-epoch search bounds are not all configurable through a single public interface.
