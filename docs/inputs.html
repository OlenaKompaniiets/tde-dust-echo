UGC 11487 / reproducible research

Files, units, and configuration

A reproducible model is defined by its physical parameters, the exact numerical input files and the active solver settings. Similar filenames or rounded values are not enough to identify the same run.

The values below belong to the archived Case A displayed on this website. Its configuration, photometry, figures and interactive data remain one matched snapshot. A later research refinement should be distributed with its own matching outputs rather than substituted into these archived labels.

1. The canonical photometry table

The physical fit uses the author-processed 22-epoch input CSV, not raw individual WISE detections. The loader requires exactly 22 rows, ordered by MJD, finite fluxes, strictly positive errors and constant per-band host levels.

Columns read by the fitUnits and meaning
mjdObserver-frame modified Julian date.
F_W1_Jy, F_W2_JyObserved total band flux density, Jy. These are not host-subtracted inputs.
sigma_W1_Jy, sigma_W2_JyEffective errors used directly in χ², Jy.
baseline_W1_mJy, baseline_W2_mJyConstant host flux densities, mJy; divided by 1000 before comparison in Jy.

The table also contains convenient mJy fluxes, statistical-error columns and excess fluxes. They are not extra independent measurements in the likelihood. Supplying an excess column in place of the total flux and subtracting the fixed host again would count the baseline twice.

σb,i,eff² = σb,i,formal² + sfloor²
sfloor ≈ 1.10 mJy

The supplied error columns already include the adopted additive floor in quadrature. The active loader does not add another floor, an additional epoch-dependent 3% fractional error or a fitted scatter term. Applying an additional floor changes the likelihood and the meaning of the reported χ².

The 1.10 mJy floor is a rounded description. For exact archive reproduction, use the supplied error columns rather than reconstructing them from rounded prose or from the statistical-error columns alone.

The fixed hosts are 8.072315984025277 mJy (W1) and 5.215414582541471 mJy (W2), corresponding to the first two NEOWISE epochs. They are not the alternative combined AllWISE+NEOWISE baseline used for some empirical excess-light-curve diagnostics. Host uncertainty is not propagated into this conditional physical fit, and the host is not a source of thermal heating.

The six continuously refined physical parameters are η, τvisc, τC, τE, opening angle and inclination. The event epoch t₀ is profiled separately. The threshold density is also fixed; it is not inferred as a gas-density measurement from WISE.

5. Units and numerical settings

Input geometry uses pc, grain radius and tabulated wavelength use μm, and the transport calculation converts to SI lengths and powers. Flux fitting uses Jy; figures commonly show mJy. Driver and transport times are rest-frame days, whereas the observed MJD differences include the factor 1+z. Reported energy-ledger values are in erg.

The configuration contains inherited numerical keys, but the active resolution is recorded separately in each run’s summary.json and provenance.json. For this archive it is 6 radial cells per population, 6 polar cells, 144 transport wavelengths, 30-day transport bins, 256 thermal rays and 512 observer samples. The driver stays at 10-day sampling. See the authoritative resolution table before changing or interpreting old n_radii, n_mu, n_phi or seed entries.

6. Fingerprints and release provenance

The archived release manifest records SHA-256 fingerprints for the distributed numerical inputs. The preparation audit specifically records byte-for-byte restoration of the canonical photometry and selected Case A fallback curve against the archived provenance. It does not make that same reconstruction claim for every other STARS history.

A filename identifies a product, while its hash identifies the bytes actually used. Keep both, along with the exact source version and active numerical settings. Do not silently replace the Vega standard with a newer CALSPEC file, substitute updated optical functions or infer the STARS bundle’s version from a citation alone. Those changes require a new provenance record and potentially a new model calculation.

The website and source repository are publicly accessible, but preparation-era release checks remain historical records. Project citation metadata and third-party attribution or redistribution terms should be resolved for a versioned release; public download availability is not itself a new data licence.
