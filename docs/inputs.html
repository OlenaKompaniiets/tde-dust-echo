Files, units, and configuration

Photometry

The current loader requires exactly 22 rows, sorted by MJD, with finite values, positive uncertainties, and constant per-band host levels.

ColumnUnit / meaning
mjdObserver-frame modified Julian date
F_W1_Jy, F_W2_JyObserved total flux density, Jy
sigma_W1_Jy, sigma_W2_JyErrors used directly in χ², Jy
baseline_W1_mJy, baseline_W2_mJyFixed host flux, mJy

The archived errors already include the adopted photometric error model. The loader does not add another floor. Do not add the floor twice. Fluxes are supplied in Jy but host levels in mJy. Case A uses fixed host values 8.072 and 5.215 mJy, respectively; host uncertainty is not propagated in this likelihood.

Source and distance constants

The inherited loader sets z = 0.01895, DL = 82.34 Mpc, MBH = 6.309573×106 M⊙, and Tsrc = 30000 K in scripts/run_v4_model_grid.py. Reusing the model for another object requires reviewing these constants, the 22-row restriction, and the t₀ search window. Changing only the input CSV is insufficient.

External data

STARS is sought in STARS_library-master, or in the directory specified by UGC_STARS_ROOT. Optical and calibration files live in data/reference. Input checksums and the restored-file provenance are recorded in release_manifest.json and AUDIT.md. Third-party redistribution terms remain a release checklist item.
