Objective function and search strategy

χ² = Σb∈{W1,W2},i [(Fbi − Hb − Fmodel,bi)/σbi]2

The likelihood fits fluxes directly. It includes no lag, width, colour, fluence, peak, or flux–flux penalty. Physical grain normalization and observer transfer determine the transient amplitude; independent W1/W2 amplitudes are not fitted. Host fluxes are fixed from the input file.

Event epoch and conditional degrees of freedom

t₀ is profiled over MJD 56500–57500, using a 10-day scan followed by bounded local refinements. The six continuously optimized physical parameters are η, τvisc, τC, τE, opening angle, and inclination. With t₀, this gives nominal conditional ν = 44 − 7 = 37. Report χ² and ν separately. This count is conditional on the selected discrete driver, fixed geometry, dust prescription, and host assumptions.

Staged search

The staged search schedules 64 balanced configurations for each of 141 STARS histories (9024 initial models). Later stages add selected configurations and refine up to 20 candidates. This is not exhaustive coverage of the continuous parameter space, nor a guarantee of the global minimum.

python -u scripts/run_v48_staged.py --workers 12

Run this only after a successful single-model benchmark. Consult configs/v48_staged_domain.json for the actual scheduled axes. A printed BEST χ² is the cumulative minimum, so a repeated BEST value does not mean every model has the same χ². unsupported_sublimation means the static-opacity solver cannot evaluate that configuration.

Local optimization

V48_PAPER_FINAL/run_parallel.py uses bounded coordinate polls and persists accepted states. It expects existing branch baseline files or checkpoints and is not the public quick-start entry point. Case A met its coordinate-poll stopping rule after 192 evaluations; this is local stationarity within the tested bounds. The historical Case B reached its evaluation budget.

Uncertainty profiles

The retained V48_UNCERTAINTIES workflow fixes one parameter and reoptimizes nuisance parameters. Thresholds Δχ² = 1 and 3.841459 correspond to nominal asymptotic 68.27% and 95% single-parameter profile intervals under regular likelihood assumptions. They are not simultaneous seven-parameter regions.

Inspect optimization failures, parameter boundaries, disconnected minima, and lower minima found during profiling before quoting intervals. The uploaded archive does not contain final validated profile intervals. The public example therefore reports point estimates, not invented errors. See the retained uncertainty README for its project-specific state dependencies.
