Install and reproduce Case A

1. Create an environment

Run these commands from the extracted repository root in Anaconda Prompt. The environment file targets Python 3.11; the accompanying validation report records the environment actually tested here.

conda env create -f environment.yml
conda activate ugc-dust
python tools/check_install.py

Alternatively, use a dedicated Python virtual environment and install requirements.txt. This file declares minimum versions, not an exact lock. The tested dependency snapshot is supplied separately.

2. Check the archived result

python tools/check_saved_case.py

Expected: total χ² = 58.95064072368716, with W1 = 19.487984248108464 and W2 = 39.46265647557869. This checks the stored data, predictions, and errors. It does not establish numerical-resolution convergence.

3. Run the physical solver

python -u tools/run_case_a.py --plots

The wrapper checks dependencies and input hashes, launches the unchanged fine solver, and writes to a new timestamped directory under results/. It reports the difference from the archived χ². Numerical runtime depends on the processor and environment; benchmark this one model before scheduling a grid.

The physical solver's legacy figure set is produced first. Corrected thermal figures are written in thermal_publication_v2/. The old thermal images are retained as legacy output and should not be used in the paper.

4. Rebuild thermal figures without fitting

python tools/plot_thermal.py --folder examples/case_a

This uses the saved thermal solution and spatial sample. No grid, optimization, or new physical assumption is introduced. See Figure conventions before interpreting the temperature scale.
