## Уточнення мінімумів перед похибками
Після оцінки чисельної точності:
```
python -u V48_PAPER_FINAL\run_final.py --mode baseline --workers 2 --maxfev 120
```
Powell оптимізує шість параметрів у нормованих координатах; t0 профілюється існуючим solver. Межі: eta 0.10–0.22; visc 100–400 d; tau_C 0.2–0.8; tau_E 1.2–3.4; theta та inc 30–55 deg. Кожна гілка має окремий STARS-драйвер. Радіуси, p, зерна, host і похибки спостережень фіксовані.
120 — бюджет викликів на гілку, не гарантія збіжності. Орієнтир лише для нових моделей за 166 с/модель: 120×166 с≈5.5 год на гілку; при двох паралельних гілках wall time такого ж порядку, але залежить від ПК і кешу. Якщо optimizer_success=false, збільшити maxfev: новий baseline стартує з уже знайденого найкращого. Наявні точні RT-розрахунки використовуються повторно.

## Пілотний профіль
```
python -u V48_PAPER_FINAL\run_final.py --mode profile --parameter eta --workers 2 --maxfev 120
```
На кожній точці параметр фіксується, решта оптимізується заново. Профіль t0_mjd фіксує час у фотометричній функції втрат та оптимізує всі шість фізичних параметрів. Для решти параметрів t0 вільний.
Можливі --parameter: eta, tau_visc, tau_C, tau_E, theta, inc, t0_mjd, all.
Початкові відхилення: 0.01,25d,0.025,0.15,2.5deg,2.5deg,20d; подвоюються, максимум 4 точки на бік. Зупинка боку при Δχ²≥3.84 або межі діапазону. Це розвідка профілю, не готова точна межа інтервалу. Повний all може бути дорогим: до 56 мінімізацій на гілку, кожна до maxfev RT-викликів. Не запускати all до оцінки пілота.

Профілі — умовні для кожного STARS, фіксованої геометрії та зерен. Значення 1 і 3.84 — асимптотичні орієнтири 68.3% і 95% для ОДНОГО параметра. На межах та при нерегулярній правдоподібності покриття не гарантоване. Методичне джерело: PDG Statistics (2025), Sec.40.4.2.3, https://pdg.lbl.gov/2025/reviews/rpp2025-rev-statistics.pdf.

Код не перетворює рідкий профіль автоматично на довірчий інтервал. Потрібне уточнення перетинів і перевірка стійкості мінімізації. Не називати набір профільних кривих posterior samples і не будувати з нього 68%/95% смуги для температури чи фотометрії. Такі смуги потребують окремої спільної вибірки параметрів або каліброваного bootstrap. Цей пакет їх не створює.

Будь-яка помилка RT зупиняє процедуру, а не перетворюється на χ²=∞ або фізично виключену модель.
